# Thư mục Screenshots

Bạn có thể thay thế các ảnh chụp màn hình phần mềm thực tế vào thư mục này:
- `dashboard.png`: Ảnh chụp bảng điều khiển chính
- `chart.png`: Ảnh chụp biểu đồ phân tích kỹ thuật
- `trading-panel.png`: Ảnh chụp panel lệnh và quản lý rủi ro

*Lưu ý: Nếu chưa có ảnh thật, website đang tự động vẽ giao diện Trading UI mô phỏng cực kỳ sắc nét bằng code SVG/CSS.*
